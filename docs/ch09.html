    ตราสารประเภทที่เป็นไปได้เกณฑ์การวัดบรรทัดตามแบบ 2ย่อหน้า
    
        
          
    หุ้นสามัญจดทะเบียนในตลาดหลักทรัพย์แห่งประเทศไทย (SET) หรือตลาดหลักทรัพย์ เอ็ม เอ ไอ (mai)เพื่อค้า หรือเผื่อขาย ตามวัตถุประสงค์ ไม่มีวัตถุประสงค์ชัดเจน = เผื่อขาย ถ้าได้อำนาจควบคุม อิทธิพล หรือการควบคุมร่วม = บริษัทย่อย บริษัทร่วม การร่วมค้ามูลค่ายุติธรรมตามราคารับซื้อคืน หรือราคาทุนหักค่าเผื่อสำหรับบริษัทย่อย ร่วม การร่วมค้า1.2 / 2.5 / 2.2–2.49.2.1, 9.4, 9.11, 9.12, 9.18
    
          
    หุ้นบุริมสิทธิจดทะเบียนตราสารทุนในความต้องการของตลาด เพื่อค้าหรือเผื่อขายมูลค่ายุติธรรม1.2 / 2.59.2.1, 9.11
    
          
    ใบสำคัญแสดงสิทธิที่ซื้อขายในตลาดหลักทรัพย์มีลักษณะอนุพันธ์ พิจารณาบทที่ 24 ก่อน (แนวการตีความ)ตามทางเลือกในบทที่ 24ตามบทที่ 2424.1, 24.3
    
          
    หุ้นบริษัทจำกัดที่ไม่ได้จดทะเบียน ถือน้อยกว่าร้อยละ 20ตราสารทุนที่ไม่ใช่หลักทรัพย์ที่อยู่ในความต้องการของตลาด เว้นแต่มีหลักฐานว่ามีอิทธิพลราคาทุนเดิมหักค่าเผื่อการลดลงของมูลค่า2.5 (หรือ 1.2 ถ้าตั้งใจขายภายใน 12 เดือน)9.2.2, 9.6, 9.12
    
          
    หุ้นบริษัทจำกัด ถือร้อยละ 20–50บริษัทร่วม เว้นแต่มีหลักฐานชัดเจนว่าไม่มีอิทธิพล หรือเป็นบริษัทย่อยเมื่อมีหลักฐานว่าควบคุมได้ราคาทุนหักค่าเผื่อ2.4 / 2.29.5, 9.6, 9.12
    
          
    หุ้นบริษัทจำกัด ถือเกินร้อยละ 50บริษัทย่อย เว้นแต่มีหลักฐานชัดเจนว่าควบคุมไม่ได้ราคาทุนหักค่าเผื่อ2.29.5, 9.12
    
          
    ส่วนได้เสียในห้างหุ้นส่วนนิยามบริษัทย่อย บริษัทร่วม การร่วมค้ารวมกิจการที่ไม่ได้ก่อตั้งในรูปบริษัทราคาทุนหักค่าเผื่อ2.2–2.4 หรือ 2.59.5–9.7
    
          
    กิจการร่วมค้าที่มีข้อตกลงควบคุมร่วมการร่วมค้า เมื่อผู้ร่วมค้ามีสิทธิในสินทรัพย์สุทธิราคาทุนหักค่าเผื่อ2.39.7, 9.12
    
          
    หน่วยลงทุนกองทุนอีทีเอฟที่จดทะเบียนในตลาดหลักทรัพย์หลักทรัพย์ในความต้องการของตลาด เพื่อค้าหรือเผื่อขายมูลค่ายุติธรรม1.2 / 2.59.2.1, 9.11
    
          
    หน่วยลงทุนกองทุนรวมเปิด ประกาศมูลค่าหน่วยลงทุนทุกวันทำการแนวการตีความตามลำดับในย่อหน้า 5.5 (ใช้นิยามใน 9.2.1 ซึ่งเป็นเรื่องที่คล้ายคลึงกันก่อน): หลักทรัพย์ในความต้องการของตลาดเมื่อซื้อขายได้ทุกวันทำการด้วยราคาที่เปิดเผย มิฉะนั้นเป็นเงินลงทุนนอกตลาด เปิดเผยนโยบายมูลค่ายุติธรรม หรือราคาทุนหักค่าเผื่อ1.2 / 2.55.5.1, 9.2, 4.19.2, 5.8
    
          
    กองทุนรวมตลาดเงินที่ถือเพื่อบริหารสภาพคล่องอาจเป็นรายการเทียบเท่าเงินสดตามเงื่อนไขในบทที่ 6ตามบทที่ 61.16.2
    
          
    พันธบัตรรัฐบาลหรือหุ้นกู้ที่ซื้อขายในตลาดตราสารหนี้ (BEX)เพื่อค้า เผื่อขาย หรือถือจนครบกำหนดมูลค่ายุติธรรม หรือราคาทุนตัดจำหน่าย1.2 / 2.59.3, 9.13, 9.14
    
          
    หุ้นกู้ที่เสนอขายในวงจำกัด ไม่มีตลาดซื้อขายตราสารหนี้ที่ไม่ใช่หลักทรัพย์ที่อยู่ในความต้องการของตลาดราคาทุนตัดจำหน่ายหักค่าเผื่อ1.2 / 2.59.2.2, 9.13
    
          
    เงินฝากประจำเกิน 3 เดือนนับจากวันที่ได้มา ไม่มีภาระค้ำประกันเงินลงทุนในลักษณะหนึ่งตามคำถาม-คำตอบของสภาวิชาชีพบัญชี ข้อ 1ราคาทุนตัดจำหน่าย (เงินต้น) ดอกเบี้ยค้างรับแยกแสดง1.2 / 2.59.1, 9.13, 4.8.1
    
          
    หุ้นกู้แปลงสภาพตราสารหนี้ที่มีอนุพันธ์แฝง พิจารณาบทที่ 24 ร่วมด้วย (แนวการตีความ)ตามประเภทและทางเลือกในบทที่ 241.2 / 2.59.3, 24
